# H2O CLI RC8 — Conversation UI redesign

This release focuses on the terminal conversation experience.

- New H2O/Bubb header and first-run welcome panel.
- Chat transcript distinguishes user, Bubb, and system messages.
- Redesigned multiline composer with a prompt rail, mode chip, and concise shortcut hints.
- Command palette hints and live status/queue visibility.
- Terminal and split views retained.
- Plan Mode and Build Mode behavior is unchanged; only their presentation is refreshed.
- No Web Dashboard files were changed.

The mascot is represented by a sky-blue water-drop glyph in terminal output. A true animated 3D mascot is not part of this terminal-only release.
